# Security policy

## Supported version

Security fixes are currently applied to the latest `main` branch and newest
GitHub release.

## Reporting

Please report vulnerabilities privately through GitHub's **Report a
vulnerability** feature instead of opening a public issue.

The companion binds only to `127.0.0.1`. Hosted access is restricted to the
exact production origin and requires a rotating pairing code. A report is
especially useful if it demonstrates origin bypass, unauthorized local file
access, command execution, unsafe archive extraction, or pairing-code leakage.

Do not include real credentials, unrelated personal information, or destructive
proof-of-concept payloads.
